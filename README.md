# Delivery Is The Only Thing I Can Do

> The world is ending. The deliveries are not.

**Delivery Is The Only Thing I Can Do** is a quiet, stylized delivery-driving game created for **GMTK Game Jam 2026** and its theme, **Count Down**.

Everyone knows the end is coming, yet everyday life continues. You drive through a long rural village, listen to a lo-fi radio, and deliver the remaining packages before the final countdown reaches zero.

## About the game

The world is inspired by **Sułoszowa, Poland**—a remarkable linear village surrounded by long strips of farmland. Roads, terrain, fields, vegetation, and settlements are assembled through procedural and generative systems.

The project was developed during the final 48 hours of the jam as a hands-on experiment in learning procedural world generation, interactive vegetation, spline-based roads, and vehicle gameplay.

## Features

- A procedurally generated linear village and surrounding farmland
- Arcade delivery-truck handling with first- and third-person cameras
- Delivery parking objectives and a world-ending countdown
- Dense interactive grass that bends around the vehicle
- An in-cab radio with a collection of chill and lo-fi tracks
- A stylized end-times sky and cinematic finale
- Windows and WebGL builds

## Controls

| Input | Action |
| --- | --- |
| `WASD` / Arrow keys | Drive and steer |
| `Space` | Handbrake |
| `C` | Change camera |
| Mouse | Look around in first person |
| Right mouse button | Look around in third person |
| `Z` / `X` | Previous / next radio track |
| `R` | Reset vehicle |
| `Esc` | Pause menu |

## Built with

- Unity 6 / Universal Render Pipeline
- C#
- Procedural spline-based roads and terrain
- GPU procedural grass on desktop, with a WebGL-compatible mesh fallback
