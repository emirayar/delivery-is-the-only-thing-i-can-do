# Free Delivery Truck Vehicle

Download the model from:
https://sketchfab.com/3d-models/free-delivery-truck-vehicle-low-poly-50cdb3c674c84224b6ebfe471ca404fe

Extract an FBX or OBJ model into this folder, then run:
`GMTK > Install Free Delivery Truck Visual`

The installer keeps `Kenney Player Exterior` in the scene but deactivates it.
It attaches the new visual to the existing driving physics root.
